# Next.js Project for Vercel

VercelへデプロイするためのNext.js（App Router + TypeScript）基本構成プロジェクトです。

## 開発サーバーの起動

```bash
npm install
npm run dev
```

## Vercelへのデプロイ手順

1. **GitHubにプッシュする**:
   - リポジトリを作成し、コードをプッシュします。

2. **Vercelと連携する**:
   - [Vercel](https://vercel.com/) にログインし、「Add New Project」をクリック。
   - GitHubリポジトリを選択して「Deploy」を押すだけで完了です。
